# Python HTML Menu App

This project is a web application that provides an information archive and a quiz evaluation system. It is built using Python and integrates HTML for the user interface.

## Project Structure

```
python-html-menu-app
├── src
│   ├── main.py          # Entry point of the application
│   ├── archive.py       # Logic for managing the information archive
│   ├── quiz.py          # Logic for quiz evaluation
│   └── templates        # HTML templates for the application
│       ├── base.html    # Base HTML template
│       ├── menu.html    # Main menu template
│       ├── archive.html  # Archive display template
│       └── quiz.html    # Quiz question template
├── requirements.txt      # Project dependencies
└── README.md             # Project documentation
```

## Usage

To run the application, execute the following command:
```
python src/main.py
```

Once the server is running, open your web browser and navigate to `http://127.0.0.1:5000` to access the main menu.
